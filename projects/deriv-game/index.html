MVP DERIV GAME

ARCHITECTURE MICROSERVICES

Laravel Gateway Python FastAPI Docker Compose OAuth2 PKCE

Statut

Prototype non encore hébergé, conçu pour fonctionner en local via services séparés.

Services

Market, Auth, Trading et gateway API.

Contexte

MVP Deriv Game est une architecture microservices pour expérimenter une gateway Laravel et des services Python FastAPI autour des flux Deriv : marché, authentification et trading.

Architecture

Gateway Laravel

Point d'entrée API avec routes versionnées et protection par X-API-Key.

Market Service

Connexion WebSocket publique à la nouvelle API Deriv.

Auth Service

OAuth2 PKCE et génération d'URL OTP avec trade_session_id.

Trading Service

Gestion des proposal, buy, sell et positions.

Qualité & Exploitation

Le projet prévoit des contrats API, des logs JSON, une corrélation via X-Request-ID, la rédaction des secrets dans les logs et des runbooks pour les incidents OAuth, WebSocket, rate limit et lancement démo.
