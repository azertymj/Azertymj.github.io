ESICTECH

SITE WEB PROFESSIONNEL

En ligne Laravel 12 Livewire 3 Tailwind CSS Vite
Voir le site

Rôle

Développement d'un site vitrine moderne avec navigation fluide et composants réutilisables.

Pages

Accueil, À propos, Services, Projets, Blog et Contact.

Contexte

EsicTech est un site professionnel conçu pour présenter l'entreprise, ses services, ses projets et ses contenus de blog. L'objectif était d'obtenir une interface moderne, responsive et simple à maintenir.

Fonctionnalités

Navigation SPA

Navigation fluide avec Livewire et wire:navigate, sans rechargement complet.

Composants

Header et footer réutilisables, structure Blade claire et pages organisées.

Design responsive

Interface moderne avec Tailwind CSS et support du mode sombre.

Contact

Page contact intégrée pour faciliter la prise de relation avec l'entreprise.

Approche Technique

Le projet s'appuie sur Laravel 12, Livewire 3, Tailwind CSS et Vite. Les routes publiques sont organisées autour des pages principales, avec des vues Blade séparées pour garder une base propre et évolutive.
